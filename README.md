# Dog vs Cat CNN Classifier

A Convolutional Neural Network to classify images of dogs and cats

## Overview

This project implements a Convolutional Neural Network (CNN) in Python to effectively classify images of dogs and cats. Utilizing deep learning techniques, the model is trained on a dataset of labeled images, allowing it to learn distinguishing features between the two classes. The project includes a Jupyter notebook for visualization and experimentation with the model's performance on test data.

## Features

- Built-in CNN model for image classification
- Training and evaluation functionalities
- Supports visualization of training metrics
- Notebook for detailed analysis and experimentation

## Quick Start

```bash
git clone https://github.com/SudeshDahale/dog-vs-cat-cnn.git
cd dog-vs-cat-cnn
pip install -r requirements.txt
python src/convolutional_neural_network.py
```

## Architecture

The monolithic architecture features a single Python module that encapsulates the entire CNN model for image classification. The main model code is located in 'src/convolutional_neural_network.py', while 'src/notebooks/convolutional_neural_network.ipynb' provides an interactive environment for exploring and analyzing the model's performance.
