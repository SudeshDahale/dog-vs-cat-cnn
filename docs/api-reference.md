# Dog vs Cat CNN Repository API Reference

**Base URL:** `http://localhost:8000/api`  
**Authentication:** Bearer JWT Token or Session Cookie

## Overview
The dog-vs-cat-cnn repository is a Python monolith that provides utilities for loading image data, defining, training, and evaluating a convolutional neural network, and an exploratory Jupyter notebook. It does not expose a web service, so there are no HTTP endpoints to document. This reference notes the absence of an API and outlines the current code‑level entry points for developers.

## Endpoints
No endpoints mapped.
