# Dog vs Cat CNN

**Base URL:** `http://localhost:8000/api`  
**Authentication:** Bearer JWT Token or Session Cookie

## Overview
This repository provides a Python package for defining, training, and saving a convolutional neural network that classifies images as dog or cat. It includes a script (src/convolutional_neural_network.py) for model construction and training, and a Jupyter notebook (src/notebooks/convolutional_neural_network.ipynb) for interactive experimentation. The code is intended for direct use as a library or script and does not expose an HTTP service.
