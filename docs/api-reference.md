# Dog vs Cat CNN - API Reference

**Base URL:** `http://localhost:8000/api`  
**Authentication:** Bearer JWT Token or Session Cookie

## Overview
This repository implements a convolutional neural network (CNN) for binary image classification (dog vs cat) using Python. It follows a monolithic ML workflow architecture and provides a programmatic API via Python modules rather than HTTP endpoints. The primary entry point is the `convolutional_neural_network` module, which exposes functions for data preparation, model definition, training, evaluation, and visualization. No web service or RESTful API is defined in this codebase.
