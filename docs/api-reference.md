# Dog vs Cat CNN Python Package

**Base URL:** `http://localhost:8000/api`  
**Authentication:** Bearer JWT Token or Session Cookie

## Overview
The repository provides a monolithic Python implementation for training and evaluating a convolutional neural network that classifies images of dogs and cats. It includes model definition, data preprocessing, training scripts, and inference utilities, but does not expose a web service or HTTP API.
